# Роль развёртывания агента

Один хост, один контейнер, обновление с остановкой
([ADR-0023](../../docs/adr/0023-deploy-with-downtime.md)). Окно слепоты равно
времени перезапуска: пропущенные минуты агент дозапрашивает сам.

## Что нужно задать

| Переменная | Обязательна | Что это |
| :--- | :---: | :--- |
| `sreagent_model_key` | да | ключ LiteLLM |
| `sreagent_session_key` | да | ключ подписи сессий веб-морды |
| `sreagent_accounts` | да | список `{login, password}`, пароль — хешем |
| `sreagent_knowledge_repo` | нет | репозиторий знаний; без него скиллов не будет |
| `sreagent_logs_url`, `sreagent_metrics_url`, `sreagent_model_url` | нет | адреса, по умолчанию боевые |
| `sreagent_logs_password` | нет | пароль VictoriaLogs |
| `sreagent_self_streams` | нет | селектор собственных потоков агента |

Хеш пароля считается самим агентом:

```bash
docker run --rm sreagent:latest hash 'пароль'
```

Считать его на стороннем сайте — значит отправить туда пароль.

## Запуск

```bash
ansible-playbook -i inventory/all-01-prod sreagent.yaml
```

Роль копирует исходники на хост и собирает образ там же: сборка Rust требует
сети до crates.io и пары минут.

## Обновление и откат

Обновление: остановка, подмена образа, старт. Ряд наблюдений восстанавливается
дозапросом, отдельной процедуры для этого нет.

Откат — возврат прежнего образа на ту же базу. Он работает, потому что каждый
запрос называет свои столбцы поимённо: лишние столбцы, добавленные новой
версией, прежней не мешают. Обратное — когда версия схемы потеряна или база
восстановлена из бэкапа — тоже не роняет агента: шаги схемы применяются по
предложению, и уже сделанное пропускается.

**Выкладка в разгар аварии стоит находок.** Прерванные расследования при
подъёме закрываются, а инциденты разбираются заново. Лучше подождать.

## HTTPS

В задачу агента не входит и делается на входе реверс-прокси. Пароль, ходящий по
голому HTTP, — дыра. Это не фигура речи: вход по логину и паролю без TLS
означает, что пароль дежурного виден в сети целиком.
