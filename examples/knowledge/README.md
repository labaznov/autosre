# Образец репозитория знаний

Это рабочее дерево, а не иллюстрация. При развёртывании оно раскладывается в
отдельный репозиторий знаний ([ADR-0015](../../docs/adr/0015-knowledge-repository.md)),
после чего живёт своей жизнью: правят его SRE, а не разработчики агента.

Здесь набор остаётся эталоном формы. Если меняется
[`docs/KNOWLEDGE.md`](../../docs/KNOWLEDGE.md) — меняется и он, одним коммитом.

```
skills/    пять стартовых скиллов: по одному на каждый вопрос агента
notes/     две заметки: известная ошибка и разбор аварии
drafts/    образец черновика — так выглядит то, что пишет агент
reports/   образцы суточного и недельного отчётов
```

Скиллы намеренно разные по устройству: один смотрит логи, второй сопоставляет
логи с метриками, третий работает по накопленной истории, четвёртый разбирает
сдвиг уровня, пятый сравнивает сутки с прошлыми. На них проверяется, что форма
фронтматтера годится не для одного случая, а набор покрывает все включённые по
умолчанию горизонты — иначе агент заводит инцидент, для которого нечем
работать. Это проверяется тестом, а не глазами.
