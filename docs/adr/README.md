# Решения по архитектуре

Каждый файл — одно решение: чем вызвано, что решили, чем за это платим и что
рассматривали взамен. Записываем **до** реализации, потому что смысл ADR —
зафиксировать причину, пока она ещё в голове.

Решение не переписывают после того, как оно воплощено в коде. Если оно
перестало годиться, заводится новое, а старое получает статус «заменено на
ADR-NNNN» или «уточнено в ADR-NNNN». Так видно, почему проект пришёл туда, где
он есть.

Пока решение не реализовано, его можно переписать на месте: терять нечего, а
плодить историю пустых развилок незачем. Именно так ADR-0013 сменил скользящее
окно на минутный бакет.
