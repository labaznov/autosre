# ADR-0025: Настройки в файле TOML, секреты из окружения

Статус: принято 17.08.2026

## Контекст

Настроек много и они не плоские: список горизонтов с шириной, периодом и
порогами; правила отбора метрик; сроки хранения; учётные записи. В переменные
окружения такое ложится плохо — список из трёх горизонтов превращается в
пронумерованные переменные, которые никто не читает.

Отдельно стоят секреты: ключ LiteLLM, пароль VictoriaLogs, ключ подписи сессий,
токен машинного доступа. Их место — не в файле, который лежит в git
инфраструктуры.

## Решение

**Файл TOML** — всё, что описывает поведение: горизонты, пороги, правила отбора
метрик, сроки хранения, адреса источников, учётные записи с хешами паролей.
Раскладывается Ansible, живёт в git инфраструктуры, читается глазами.

**Окружение** — только секреты. В файле их не бывает. Отсутствие секрета
останавливает старт ([ADR-0007](0007-local-inference.md),
[ADR-0020](0020-login-and-password.md)).

Конфигурация проверяется при старте: неизвестное поле — предупреждение в
журнале, некорректное значение — остановка.

## Следствия

- Настройка воспроизводима: развернуть агента заново — значит взять тот же файл.
  История правок видна в git инфраструктуры вместе с причиной.
- Пороги не меняются на ходу из веб-морды: правка файла и перезапуск. Перезапуск
  дешёвый ([ADR-0023](0023-deploy-with-downtime.md)), а воспроизводимость на
  этом этапе важнее удобства. Если окажется, что пороги крутят ежедневно, это
  решение придётся пересмотреть — и это будет честный сигнал, а не догадка.
- Граница «файл или окружение» соблюдается строго: один секрет, попавший в файл,
  утечёт в git инфраструктуры и останется там навсегда.
- Предупреждение вместо остановки на незнакомом поле позволяет откатить агента
  на версию назад, не откатывая конфигурацию.

## Альтернативы

- **Всё через переменные окружения.** Привычно для докера и не выражает ни
  списка горизонтов, ни правил отбора метрик.
- **Настройки в базе с правкой через веб-морду.** Удобно дежурному и лишает
  настройку воспроизводимости и истории: «почему у нас такой порог» станет
  вопросом без ответа.
