# ADR-0007: Инференс на своём стенде через OpenAI-совместимый API

Статус: принято 14.08.2026

## Контекст

Логи прода содержат внутренние адреса, имена сервисов и данные клиентов.
Интернет на контуре «скорее нет, чем да». При этом рассуждение и tool-calling
у локальной модели 12B в q4 заметно слабее внешних API.

## Решение

Первый этап работает на существующем стенде: llama.cpp за LiteLLM, четыре
инстанса модели на четырёх T4. Агент обращается по OpenAI-совместимому API.

Ключ доступа приходит из окружения; значения по умолчанию в коде нет — без
ключа агент не стартует.

## Следствия

- Данные не покидают контур, стоимость инференса нулевая, работа не зависит от
  внешней доступности.
- Порядок скорости известен: около 24 токенов в секунду на декоде. Отсюда
  жёсткие лимиты промптов и ограниченный добор данных (ADR-0002).
- Слабый tool-calling — это данность, под которую спроектирован конвейер, а не
  недостаток, который надо лечить промптами.
- Смена модели или переезд на внешний API не затрагивает ядро: за границей
  OpenAI-совместимого API можно поменять всё.
- Форма ответа фиксируется схемой на стороне сервера, а не разбором текста.

## Альтернативы

- **Внешний API.** Качество выше на порядок, но данные уходят наружу, а
  интернета может не быть.
- **Новое железо под модель 30B+.** Снимает потолок рассуждения, но ставит
  проект в зависимость от закупки.
- **Локальная плюс внешняя по кнопке.** Разумно позже; сейчас удваивает
  сопровождение промптов ради этапа, где ещё нет базовой петли.
