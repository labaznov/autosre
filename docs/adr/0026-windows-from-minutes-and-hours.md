# ADR-0026: Окно горизонта собирается из минут и часов сразу

Статус: принято 17.08.2026 · уточняет [ADR-0013](0013-minute-buckets.md)
и [ADR-0022](0022-retention.md)

## Контекст

Горизонт судит по базовой линии из 24 прошлых окон
([ADR-0013](0013-minute-buckets.md)). Суточному горизонту это 25 суток истории,
а минутные бакеты по [ADR-0022](0022-retention.md) живут неделю: дальше они
свёрнуты в часовые. Запрос окон читал только минутные, поэтому суточный
горизонт не мог собрать базовую линию **никогда** — он был включён в поставке и
вечно писал в журнал «базовой линии ещё нет». Заметить это по поведению нельзя:
агент выглядит работающим, просто молчит.

## Решение

Окно собирается из обеих таблиц: минутные бакеты дают свежую часть, часовые —
давнюю. То же для покрытия: свёрнутый час считается за шестьдесят снятых минут,
потому что отметки минут живут столько же, сколько сами минутные бакеты, и за
их сроком единственное свидетельство, что время снималось, — существование
часа.

Складываются они по своему правилу для каждого вида: счётчик суммируется,
уровень усредняется по числу минут, которые за значением стоят — час весит
шестьдесят минут, минута одну.

## Следствия

- Суточный горизонт заработал, и память до года из [ADR-0022](0022-retention.md)
  впервые пригодилась не только отчётам.
- Свёртка удаляет минуты в одной транзакции с созданием часа, поэтому одно и то
  же время не попадает в оба слагаемых. Этот инвариант теперь несёт детекцию, а
  не только уборку — ломать его нельзя.
- Час на границе окна попадает в него целиком, отчего окно может «сняться»
  больше чем на свою ширину. Покрытие подрезается шириной: известнее, чем
  полностью, окно не бывает.
- Давняя часть базовой линии грубее свежей: у часа нет минутной формы. Для
  сравнения суток с сутками это несущественно, для пятиминутного горизонта было
  бы враньём — но ему часы и не нужны.

## Альтернативы

- **Держать минутные бакеты месяц.** Ровнее считается, но объём базы вчетверо
  больше ради истории, к которой обращается один горизонт из трёх.
- **Дать суточному горизонту короткую историю, 7 окон вместо 25.** Помещается в
  недельный срок, но робастная медиана на семи точках шатается, а
  [ADR-0016](0016-observed-metrics.md) и так предупреждает, что тренд она видит
  плохо.
- **Выключить суточный горизонт.** Честно по отношению к коду и бесполезно по
  отношению к делу: медленные беды видны только на нём.
