# ADR-0004: Коннекторы — трейт плюс фичи сборки

Статус: принято 14.08.2026

## Контекст

Источников со временем будет много: Victoria-стек сейчас, дальше Zabbix, Jira,
чужие системы мониторинга. Разброс как у Datadog. При этом у конкретного
заказчика работает три источника из двадцати, и тащить к нему код и зависимости
остальных незачем.

## Решение

Коннектор — крейт, реализующий общий трейт источника. Набор коннекторов
собирается фичами Cargo под конкретную систему. Ядро агента знает только трейт
и не знает ни одного коннектора по имени.

## Следствия

- Один процесс в эксплуатации: нет сетевых хопов, нет N демонов, отладка идёт
  в одном журнале. Пилот на MCP-сервере показал обратное.
- Типы проверяются компилятором: коннектор не может вернуть форму, которую ядро
  не ждёт.
- Новый коннектор требует пересборки. Для внутреннего продукта это приемлемо,
  для поставки заказчику — это ещё и способ не отдавать лишнее.
- Граница трейта должна быть достаточно узкой, чтобы позже за ней можно было
  спрятать внешний процесс, если понадобится подключать чужое без пересборки.

## Альтернативы

- **Внешние процессы по MCP.** Добавление без пересборки и любой язык, но
  эксплуатация умножается на число источников.
- **Всё в одном бинаре без фич.** Проще собирать, но образ тянет код и
  зависимости систем, которых у заказчика нет.
