# sreagent

Агент диагностики: смотрит логи и метрики прод-системы, замечает отклонения,
проводит первичное расследование и показывает дежурному SRE разбор — что
случилось, на что это похоже из уже известного, куда смотреть дальше.

Агент не чинит. Он сокращает время до обнаружения и время до понимания.

Состояние: спецификация. Кода пока нет — и это осознанно.

## Коротко об устройстве

Конвейер из трёх решателей по возрастанию цены: числовой детектор находит
отклонения, короткий запрос к модели отсеивает шум, полное расследование
разбирает то, что осталось. Анализ идёт на горизонтах — по умолчанию 15 минут,
час и сутки, — и у каждого свой вопрос к системе.

Знание системы живёт вне кода: скиллы анализа и база известных ошибок — это
markdown в git, который пишут сами SRE. Агент дописывает туда черновики,
принимает их человек.

Стек первого этапа: Rust, VictoriaLogs и VictoriaMetrics, локальная модель за
LiteLLM, выкладка Ansible.
